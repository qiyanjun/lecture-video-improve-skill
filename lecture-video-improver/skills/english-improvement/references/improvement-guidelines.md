# English Improvement Guidelines — Common ESL Patterns

Reference examples for the most frequent non-native English patterns found in video content.

---

## Articles (a / an / the)

| Error | Fix | Rule |
|-------|-----|------|
| "I will open application" | "I will open the application" | Specific, known thing → use "the" |
| "This is very useful knowledge" | "This is very useful knowledge" | Abstract uncountable → no article |
| "Let me show you example" | "Let me show you an example" | First mention, countable → "a/an" |
| "Click on save button" | "Click the Save button" | UI elements are usually "the" |

---

## Prepositions

| Error | Fix |
|-------|-----|
| "I will explain you this" | "I will explain this to you" |
| "Let's talk about how to do it" | ✓ correct |
| "depends of your settings" | "depends on your settings" |
| "good in English" | "good at English" |
| "interested on this topic" | "interested in this topic" |
| "different of the others" | "different from the others" |

---

## Tense Consistency

Keep the same tense throughout a section unless there is a reason to shift.

| Error | Fix |
|-------|-----|
| "First, click here. Then you selected the file." | "First, click here. Then select the file." |
| "In this video I showed you how to… and then we will see…" | Pick one: past OR future frame, stay consistent |

---

## Word Order

English word order: Subject → Verb → Object → Manner → Place → Time

| Error | Fix |
|-------|-----|
| "I will you show how to do it" | "I'll show you how to do it" |
| "Please click slowly the button" | "Please click the button slowly" |
| "Today we will learn together in this lesson" | "In this lesson, we'll learn together today" |

---

## Wordy / Unnatural Phrases

| Replace | With |
|---------|------|
| "due to the fact that" | "because" |
| "in order to" | "to" |
| "at this point in time" | "now" |
| "for the purpose of" | "to" / "for" |
| "it is important to note that" | "note that" |
| "as you can see on the screen" | "as you can see" |
| "I would like to show you" | "Let me show you" |
| "what we are going to do is" | "we'll" |

---

## Subject-Verb Agreement

| Error | Fix |
|-------|-----|
| "The settings is wrong" | "The settings are wrong" |
| "Everyone have their own style" | "Everyone has their own style" |
| "The number of files are large" | "The number of files is large" |

---

## Spoken English Naturalness Tips

These apply especially to scripts and transcripts that will be spoken aloud:

- Use contractions (I'll, we're, you'll, it's) — they sound more natural when spoken
- Short sentences are easier to follow when listening
- Rhetorical questions engage viewers: "So how do we fix this?"
- Transition phrases help: "Now let's move on to…", "Here's the thing…", "As you can see…"
- Avoid starting too many sentences with "So" or "And" — vary your openers

---

## Subtitle-Specific Rules

When editing .srt or .vtt files:
- Keep improved text close to the original character count — subtitle space is limited
- One idea per subtitle block where possible
- Avoid long dependent clauses — split them if needed
- Never edit timing lines (00:00:01,000 --> 00:00:04,000)
- Never edit sequence numbers (1, 2, 3…)
- Never edit the WEBVTT header line
